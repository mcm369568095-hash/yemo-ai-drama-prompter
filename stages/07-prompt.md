### S6.1 首帧图提示词

```bash
"$PY" "$SK/frame_prompt.py" "$WD" --apply       # → prompts/f_cNN.txt
```

首帧图必须与出片画幅**严格同比例**，否则被裁切、构图走样。

### S6.2 视频提示词（四段式 / 七段式）

```bash
"$PY" "$SK/shot_prompt.py" "$WD"                # 干跑：看提示词 + lint
"$PY" "$SK/shot_prompt.py" "$WD" --apply        # → prompts/v_cNN.txt
```

通用四段式（本技能原创）：

```
【画面】<首帧画面 + 角色一致性锁 + 场景 + 时间/天气>
【动作】<时间轴分段：第0-2秒 / 第2-4秒 / 第4-6秒，每段一个物理动作>
【镜头】<景别 + 运镜 + 光位 + 构图>
【约束】<No native dialogue / 无字幕无水印 / 时长>
```

**为什么是四段**：模型只抓前 30 个字。四段把「谁在场」放最前，
把「不要什么」放最后（否定词只有字幕/水印/文字/畸形这四类真听得懂）。

### S6.3 指纹校验

```bash
"$PY" "$SK/asset_lock.py" "$WD" verify          # 指纹过期数必须为 0
```

## 提示词写作铁律

1. **资产先行，不锁定不生成。** 冻结块里的角色描述，一个字都不许自己改写。
2. **一镜一运镜。** 写两种，模型给你一团抖动。
3. **情绪不写抽象词。** 它不懂「悲伤」，懂「低头、肩膀轻颤、手指攥住衣角」。
4. **画面上的「不要」改肯定式。** 「不要换脸」无效；写「五官/发型/服装/比例与参考图完全一致」。
5. **否定词只留给字幕/水印/文字/畸形。** 只有这几类模型真听得懂。
6. **单镜 3~6 秒。** 长镜必崩。
7. **动作句最多 2 个复合动作**（超过会肢体融化）。
8. **纯环境句挪出时间轴**（写在时间轴里会出现空动作段）。
9. **提示词控制在 600 字内** —— 超过 800 字模型开始丢信息。
   需要长文时才切七段式。

## 常见坑

| 坑 | 症状 | 解法 |
|---|---|---|
| **改了 cast.json 没 sync** | `verify` 点出哪几份过期 | `asset_lock.py sync` 再 `--force` 重刷 |
| **多视图板直接喂 --edit** | 整板复刻成**多人合影** | 只用干净单图锚定 |
| **单镜塞太多动作** | 肢体融化 | 解耦成两句或拆两镜 |
| **提示词写成散文** | 模型只抓前 30 字 | 用四段式分块 |
| **提示词写成关键词** | 出来干巴巴 | 动作要写成完整句子 |
| **否定词滥用** | 「不要换脸」无效 | 改成肯定式描述 |
