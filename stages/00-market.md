# 阶段 0 · 选题与 IP 评估

> **一句话**：在动笔之前，先决定这个故事值不值得拍。
> 🔴 实测教训：36 次选题里，没有一个技能先停下来让人挑方向 —— 这是最大的浪费。

---

## 何时进这一阶段

- 用户只有一句话创意 / 一个题材方向
- 用户手上有一本小说，要先判断能不能改
- 用户问「这个题材能不能做」

---

## 输入 / 输出

| | 内容 |
|---|---|
| **输入** | 一句话创意、题材方向、或小说正文/梗概 |
| **输出** | `选题卡.md`（一句话卖点 + 五维自评 + 时钟 + 爽点画面） |
| **下游** | 阶段 1（改编）或 阶段 3（结构） |

---

## 步骤

### 步骤 0.1 —— 先问，不要自己定

🔴 **本技能和别的技能最大的区别：开写之前一定会停下来问。**

如果用户给了多个方向，或者方向不明确，**必须先问**：

```
1. 剧名/题材方向？（没有就给 3 个方案让用户挑）
2. 篇幅？（60 集 × 90 秒 / 30 集 × 120 秒 / 单条 60–180 秒短片）
3. 平台调性？（红果爆款 / 抖音竖屏 / 出海英文 / 品牌定制）
4. 画幅？（9:16 竖屏 / 16:9 横屏）
```

🔴 **给方案时，3 个方案必须是 3 种不同的故事类型**，不能是同一个故事换名字。
    （实测：同一个技能跑 3 次，12% 落进同一类型；不同技能之间只有 2.4%。
    给三个雷同方案等于没给。）

### 步骤 0.2 —— 定时钟

从四种时钟里挑一个挂上去（见 `references/短剧节奏与付费卡点.md`）：
倒计时 / 周期拆封 / 阶梯升级 / 双线汇合。

没有时钟的故事，**中段必塌**，直接打回。

### 步骤 0.3 —— 过 IP 评估 6 问

| 问 | 否 = 扣分 |
|---|---|
| 主角有没有**具体可演的**能力？ | 必崩 |
| 冲突能不能**当众发生**？ | 不上屏 |
| 有没有**可被看见的倒计时**？ | 中段必塌 |
| 对手能**升 3 档**吗？ | 撑不过 10 集 |
| 主场景 ≤ 8 个？ | 成本失控 |
| 关键转折靠不靠**内心独白**？ | 上屏失败 |

**6 是 = A 级｜4–5 是 = B 级｜≤3 是 = C 级（建议换故事）**

### 步骤 0.4 —— 反套路 + 反默认人名

- 对照 `references/爆款选题与爽感公式.md` 第五节「反套路清单」，命中就换方向。
- 起名前查「模型默认人名黑名单」（小满 / 顾承泽 / 国栋 / 女主姓沈 / 名字带禾 / 带砚）。

### 步骤 0.5 —— 写选题卡

```markdown
# 选题卡 ·《剧名》

**一句话卖点**：（谁 + 被怎么了 + 要干什么，20 字内）
**主角身份**：（具体职业，不是"厉害的人"）
**对手与 3 档升级**：
**金手指与代价**：（能力 + 破坏它的规则）
**时钟**：（四选一，并写出它在画面上长什么样）
**爽点画面**：（当众落地的那一幅画）
**续航**：（60 集的事件量从哪来）
**上屏自检**：（关键信息在不在画面上）
**五维自评**：卖点 / 新意 / 冲突和爽点 / 续航 / 上屏 各 1–5 分
```

---

## 铁律

1. **必须先问再写**，不许自己定一个就开写。
2. **金手指必须配代价规则**，没有代价 = 没有冲突。
3. **爽点必须当众落地**，镜头外兑现的爽点等于没有。
4. **关键信息必须在画面上**，靠字幕/内心独白的一律改掉。
5. **人名避开模型默认黑名单。**

---

## 常见坑

| 坑 | 症状 | 解法 |
|---|---|---|
| **三个方案一个故事** | 用户挑了等于没挑 | 强制三个不同故事类型 |
| **隐藏身份套路** | 全职太太其实是传说级律师 | 换成真职业 + 真麻烦 |
| **爽点在心里** | 「她知道真相了」 | 换成当众背出批号 |
| **无代价金手指** | 想干嘛干嘛 | 加一条破坏它的规则 |
| **名字全是默认值** | 沈曼、顾承泽、小满 | 查黑名单，按年代分层起名 |
