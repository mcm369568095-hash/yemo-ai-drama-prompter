# 阶段 4 · 剧本与对白

> **一句话**：台词短，情绪落在物件上，每集 1–2 分钟装得下。
> 这是 33 份盲测稿里 4 个「三次全赢」技能的共同做法。

---

## 何时进这一阶段

- 分集大纲已定，要写具体剧本
- 用户直接给大纲说「把第 1–3 集写出来」

---

## 输入 / 输出

| | 内容 |
|---|---|
| **输入** | 分集大纲 + 人物小传 + 时长账本 |
| **输出** | `剧本.md`（中文场号制） |
| **下游** | 阶段 5（审稿）→ 阶段 6（分镜） |

## 步骤

### 步骤 4.1 —— 定单集骨架

```
开场 5–10 秒    直接进冲突，不铺垫（冷开场）
↑ 加压 20–30 秒 对手出手，压力加到主角身上
↓ 反击 30–40 秒 主角用她的能力/记忆/专业拆招
钩子 5–10 秒    停在下一件事揭晓的前一秒
```

**节拍数按时长选**：30–60 秒用 6 拍｜1–3 分钟用 9 拍。

### 步骤 4.2 —— 写场号

标准**中文场号制**（集-场 / 日夜 / 内外 / 地点）：

```
1-1　日　外　江家别墅·后院石板地

人物：周桂兰、刘凤琴

△ 黄色橡胶手套攥着硬毛刷，在大理石上来回刷。周桂兰跪着，膝上一副洗旧的蓝色护膝。
字幕：周桂兰　保洁员　上工第一天
△ 台阶上，刘凤琴捏着一串钥匙。

刘凤琴：缝里也刷。
周桂兰：哎。
刘凤琴：这块地晦气。两个月前，家里一个小保姆从楼上跳下来，就摔在这儿。

△ 刷子停了一拍。

周桂兰：摔在哪块？

△ 刘凤琴用鞋尖点了点。

刘凤琴：你膝盖底下。

（第 1 集完）
```

**符号约定**：

| 符号 | 用途 |
|---|---|
| `△` | 动作描写 |
| `字幕：` | 人物身份卡 / 手机屏幕文字 |
| `（画外）` | 画外音 |
| `（VO）` | 配音/语音 |
| `（回忆）` | 回忆段落（要给视觉标记） |
| **不写转场** | 转场交给剪辑/分镜 |

### 步骤 4.3 —— 控字数

```
第 1 集约 610 字 ≈ 1 分 30 秒
第 2 集约 800 字 ≈ 2 分钟
```

🔴 **折算标准：正文非空白字数 ÷ 400 字/分钟。**
（竖屏短剧切换快，比长剧的 270–330 字/分钟密。）

```bash
"$PY" "$SK/script_qc.py" 剧本.md       # Q1 会报超时的集
```

### 步骤 4.4 —— 对白三指标

| 指标 | 要求 |
|---|---|
| 长度 | 单句 ≤ 15 字，多数短单句 |
| 区分度 | 遮住人名能听出是谁（每人一套语言指纹） |
| 信息量 | 一句只装一个意思，不带解释 |

### 步骤 4.5 —— 情绪落在物件上

🔴🔴 **这是赢家和输家的分水岭。**

| ❌ 心理描写 | ✅ 物件动作 |
|---|---|
| 她心如刀割 | 她用拇指擦屏幕上姑娘的脸，像擦一块污渍。擦不掉 |
| 他很紧张 | 茶上的热气是直的 —— 她站了有一会儿了 |
| 她崩溃了 | 张妈在厨房里哭到发抖 |

**通读一遍，把所有「心里想/感觉到/回忆起/意识到」改成看得见的动作或物件。**

### 步骤 4.6 —— 集尾钩子

五种高强度钩子（见 `references/短剧节奏与付费卡点.md`）：
揭晓前一秒 / 身份错位 / 物件响起 / 当众指认 / 倒计时刷新。

### 步骤 4.7 —— 更新记忆文件

```bash
"$PY" "$SK/series_bible.py" "$WD" qc
```
每集写完更新伏笔表、时间线、物品账本、出场登记。

---

## 铁律

1. **每集 3–5 场**，多了必超时。
2. **单句台词 ≤ 15 字。**
3. **OS/VO 不超过对白的 1/3**（旁白撑起来的戏不能上屏）。
4. **不写心理描写**，一律转译成动作。
5. **开场 3 秒内必须有事件**，不许铺垫。
6. **每集必写出去状态。**

---

## 常见坑

| 坑 | 症状 | 解法 |
|---|---|---|
| **每集太满** | 明显超过 2 分钟 | 按 400 字/分钟折算，砍场 |
| **关键推理靠 OS** | 「旁白解释了一切」 | 改成角色当众看见证据 |
| **台词一腔调** | 遮住人名分不出谁 | 每人发语言指纹 |
| **套话形容词** | 「声音冷得像冰」 | 全删，换物件动作 |
| **钩子含蓄** | 「她拦下一辆网约车」 | 换事件式钩子 |
