# 阶段 2 · 人物与角色资产

> **一句话**：人物要先定稿，才能进流水线。
> 本阶段同时管**叙事层面的人物小传**和**视觉层面的角色定稿图**。

---

## 何时进这一阶段

- 选题定好了，要立人物
- 改编方案定了，要提取角色
- 用户直接说「帮我做几个角色」

---

## 输入 / 输出

| | 内容 |
|---|---|
| **输入** | 选题卡 / 改编方案 |
| **输出** | `人物小传.md` + `cast.json` + `cast/定稿/*.png` + `asset_lock.json` |
| **下游** | 阶段 3（结构）→ 阶段 6（分镜） |

## 步骤

### 步骤 2.1 —— 写人物小传（八要素）

每人一份，缺项即不合格（详见 `references/人物塑造与对白.md`）：

```
表面身份 / 真实过去 / 为什么留下 / 能力（她的武器）/ 底线
弱点 / 弧线 / 标志物 / 说话方式
```

**三条硬要求**：
1. **真实过去必须带具体数字和时间**（"每月 3000 块，打了五年，一次没断"）
2. **为什么留下时，钱要排在最后**
3. **标志物后面必须变成物证**

### 2.1.1 配角：过工具人检测

每个配角必须有：自己的动机、自己的底线、自己的转变。

### 2.1.2 反派：过脸谱化检测 + 建公平线索表

```markdown
| 集 | 线索 |
|---|---|
| EP03 | 送汤时，视线在药盒周五那格停了一下 |
| EP06 | 主角当众背出批号，窗边的她手指收紧 |
```

### 2.1.3 起名字：查黑名单 + 年代分层

```
50 后：桂兰 / 国栋 / 振海
70 后：曼 / 承泽 / 凤琴
00 后：小满 / 屿
```
🔴 黑名单：小满（过量）、顾承泽、国栋、女主姓沈、名字带「禾」、带「砚」。

### 步骤 2.2 —— 生成角色定稿图（视觉）

🔴 **这一步解决「角色定稿图从哪来」** —— 从一段文字长出来。

```bash
PY="python"
SK="<本技能>/scripts"
WD="<你的项目目录>"

"$PY" "$SK/gen_char_sheet.py" "$WD" init --name 林晚 --role 主角 \
  --archetype "1位知性清冷办公室御姐" \
  --style "韩系3D二次元OC建模，OC渲染人物设定稿" \
  --face "淡粉清透妆容，碎刘海，无框细边眼镜" \
  --hair "黑色半扎高马尾长发" \
  --outfit "藏青色无袖高领紧身背心，灰色褶皱包臀短裙" \
  --skin "冷白细腻肌肤" \
  --light "影棚柔和柔光，浅灰色纯色简约背景，面料细节清晰"
```

🔴 **中文名千万别交给模型渲染**（实测把「李梦**姝**」写成「李梦**妹**」）。
正解两步走：
1. prompt 里把名字区改成「左侧留出竖排空白区、不写任何文字」
2. 出图后用 PIL 用微软雅黑 `C:/Windows/Fonts/msyhbd.ttc` 逐字补写

产物（`cast/定稿/`）：

| 文件 | 用途 |
|---|---|
| `<name>_设定图.png` | **角色圣经**（四宫格 + 左下角 Q 版），人看 + 一致性校验，**不喂出图** |
| `<name>_全身.png` | `ref_main`（干净单图，喂首帧 `--edit`） |
| `<name>_特写.png` | `ref_face`（近景/特写用） |

🔴🔴 **多角色/多视角图脸不一致的血案**：
设定图、全身、特写各自独立从真人自拍图生图 = 让模型把真人「翻译」N 次，
版面里单人占比越小，脸越走形。

**正解**：先跑出一张用户认可的单张（通常是特写），**把它当唯一锚**喂回去生成其余所有图。
prompt 写「参考图是本角色唯一面部真相，逐处复刻，不得改动/瘦脸/放大眼睛」。

### 步骤 2.3 —— 建角色卡

```bash
"$PY" "$SK/cast_card.py" "$WD" init --name 林晚 --role 主角 \
  --ref cast/定稿/林晚_全身.png \
  --features "26岁女性，圆脸，黑色齐肩发中分，米白色高领针织衫，浅灰色长款风衣"
"$PY" "$SK/cast_card.py" "$WD" audit
```

### 步骤 2.4 —— 资产冻结（指纹）

```bash
"$PY" "$SK/asset_lock.py" "$WD" init     # cast.json → asset_lock.json（含 md5 指纹）
"$PY" "$SK/asset_lock.py" "$WD" audit    # 缺锚定图/缺特征 → exit 2，不许往下走
```

### 步骤 2.5 —— 建连载记忆

```bash
"$PY" "$SK/series_bible.py" "$WD" init --title "我的短剧" --episodes 60
```
→ 生成 `bible/` 七份记忆文件（角色档案、伏笔表、时间线等）

## 铁律

1. **人物定稿图先生成，再冻结。** 顺序不能反。
2. **参考图只给单人**（指喂出图的锚定图）。多视图板/三视图/多人合影直接喂 `--edit`
   会被整板复刻成**多人合影**，是血案级踩坑。
3. **设定图只作角色圣经给人看，不进出图管线。**
4. **中文名字不交给模型渲染**，出图后 PIL 补写。
5. **多图之间用唯一锚**，不要各自独立图生图。
6. **改了 `cast.json` 必须 `sync`**，否则指纹过期。

---

## 常见坑

| 坑 | 症状 | 解法 |
|---|---|---|
| **图生图脸走形** | 三张图三个人的脸 | 用唯一锚串联 |
| **设定图被复刻成合影** | 四宫格整板出现在成片里 | 只用干净单图锚定 |
| **名字写成形近字** | 李梦姝 → 李梦妹 | PIL 补写 |
| **--extra 参数不认** | argparse 未注册 | 走 `--spec-json spec.json` |
| **改了角色没同步** | 提示词还用旧描述 | `asset_lock.py sync` |
