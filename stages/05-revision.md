# 阶段 5 · 审稿、质检与去 AI 味

> **一句话**：交稿前必过三关 —— 机器扫、人工读、清稿。
> 🔴 实测：120 场盲比里，**110 场的判决理由提到「正文夹带的元数据要删掉才能用」**。

---

## 何时进这一阶段

- 剧本写完了，要审稿
- 用户拿一份现成剧本来说「帮我看看」「帮我改」

---

## 输入 / 输出

| | 内容 |
|---|---|
| **输入** | 剧本 / 大纲 / 对白 |
| **输出** | `审稿报告.md`（分层问题 + 三级严重度） + `剧本_清稿.md` |
| **下游** | 阶段 6（分镜） |

---

## 步骤

### 步骤 5.1 —— 先问审查模式

```
1. 只审不写，还是要边审边改？
2. 是单集、前三集，还是全剧？
3. 用途：AI 出片 / 平台投稿 / 出海英文？
```

🔴 **只审不写时，绝不擅自重写** —— 先给诊断，等用户确认再动笔。

### 步骤 5.2 —— 机器扫（Q 系列规则）

```bash
"$PY" "$SK/script_qc.py" 剧本.md              # 单集
"$PY" "$SK/script_qc.py" 剧本.md --strict      # 严格档（含合规）
"$PY" "$SK/script_qc.py" 剧本.md --json        # 机器可读
"$PY" "$SK/series_bible.py" "$WD" qc           # 全剧连载
```

| 规则组 | 内容 |
|---|---|
| **Q1–Q12** | 单集硬规则（时长/场数/钩子/动作解耦/元数据…） |
| **Q13–Q18** | 上屏检查（爽点落地/情绪物证/配角底线…） |
| **Q19–Q23** | AI 味检查（套话/排比/空词/解释/总结…） |
| **S1–S8** | 全剧规则（卡点位置/分卷/中段反转/时钟…） |

**合格线**：
```
Q1–Q12 零命中 + Q13–Q18 零命中  →  可交付
命中 1–2 条                     →  改完再审
命中 ≥3 条                      →  打回重写
```

### 步骤 5.3 —— 问题分三级

```
🔴 必须改（影响上屏/合规/超时）
🟠 建议改（影响观感）
🟡 可保留（风格选择）
```

**报告结尾必须邀请作者反驳** —— 有些「问题」是有意为之。

### 步骤 5.4 —— 去 AI 味

六种味道逐一扫（详见 `references/去AI味与合规.md`）：
套话味 / 排比味 / 空词味 / 解释味 / 总结味 / 完整味。

**三个动作**：
1. 抽象换物理
2. 长句砍短句
3. 加断句、答非所问、留半句

### 步骤 5.5 —— 合规终审

过广电 16 号令 11 条红线 + 短剧高发雷区（价值观/炫富/迷信/暴力/医疗）。

**终审清单三层**：内容 / 形式（AI 标识预留位、备案号预留位）/ 交付。

### 步骤 5.6 —— 清稿（🔴 最关键）

```bash
"$PY" "$SK/script_qc.py" 剧本.md --clean -o 剧本_清稿.md
```

剥掉正文里夹带的所有元数据：

```
【所属阶段】第 2 幕          ← 删
【本集结算】爽点 +2          ← 删
（伏笔，第 44 集兑现）        ← 删
[连续性] 药盒位置需一致       ← 删
预估 90.8 秒                 ← 删
EPISODE_ID: EP003            ← 删
SCRIPT_VERSION: v1.2         ← 删
认领爽点：□ ○ △              ← 删
[自检表] 钩子 ✓ 人物 ✓       ← 删
```

🔴 **交付给下游的一定是清稿后的版本。** 夹带元数据的稿子，
在盲评里几乎每场都会被扣。

## 审稿报告模板

```markdown
# 《剧名》审稿报告

**审查范围**：第 1–3 集 ｜**模式**：只审不写

## 一句话判断
（这部剧现在最大的问题是什么，一句话说完）

## 🔴 必须改（N 条）
### Q1 时长超标
- 位置：第 2 集
- 证据：「第 2 集约 1100 字 ≈ 2 分 45 秒」
- 建议：砍掉 2-3 与 2-4 两场，或拆成两集

## 🟠 建议改（N 条）
## 🟡 可保留（N 条）

## 分项自评
| 维度 | 评分 | 说明 |
|---|---|---|
| 钩子 | | |
| 人物 | | |
| 结构 | | |
| 对白 | | |
| AI 味 | | |
| 可用性 | | |

---
以上为诊断结论。有不同意见请直接反驳，我按你的意见再改。
```

---

## 铁律

1. **只审不写时绝不擅自重写。**
2. **机器扫之前先人工读一遍** —— 机器只报模式，读不出节奏。
3. **报告结尾邀请作者反驳。**
4. **交付前必须清稿。**
5. **合规红线零容忍。**
