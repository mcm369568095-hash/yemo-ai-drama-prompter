# 阶段 1 · 改编（小说 → 剧本）

> **一句话**：小说是「想给你看」，剧本是「拍给你看」。
> 改编的本质是**把心理描写和全知叙述，翻译成演员能演的动作**。

---

## 何时进这一阶段

- 用户手上有一本小说 / 长文 / 长会话角色扮演记录，要改成短剧
- 用户要求「把这篇文章改成剧本」

🔴 没有原著时跳过本阶段，直接进阶段 3（结构）。
（实测：为改编小说设计的技能，在无原著时表现最差。）

---

## 输入 / 输出

| | 内容 |
|---|---|
| **输入** | 小说正文 / 章节 / 梗概（超过 50KB 分批读） |
| **输出** | `01_原作事实账本.md` + `02_改编方案.md` + `03_时长账本.md` |
| **下游** | 阶段 2（人物）→ 阶段 3（结构） |

---

## 步骤

### 步骤 1.1 —— 建原作事实账本

🔴 **先记账，再动刀。** 账本错了，后面全错。

```markdown
# 原作事实账本 ·《书名》

## 事实卡（每章 100–300 字）
### 第 1 章
- 时间：｜地点：｜在场人物：
- 发生了什么：
- 新出现的信息：
- 与前文的因果：

## 两条时间线对照
**故事发生顺序**：1→5→3→7（原作倒叙）
**作者呈现顺序**：1→2→3→…（原文顺序）

## 六维拆书
| 维度 | 评分(1-5) | 说明 |
|---|---|---|
| 剧情强度 | | 每章逐章打分 |
| 情绪强度 | | |
| 描写密度 | | |
```

### 步骤 1.2 —— 判 IP 等级

用阶段 0 的 IP 评估 6 问打分，A/B/C 分级。
**C 级直接告诉用户：这个故事不适合改短剧，建议换。**

### 步骤 1.3 —— 剥离（改编四步之第一步）

从原文里剥掉**拍不出来的东西**：

| 拍不出来的 | 处理方式 |
|---|---|
| 心理描写（她心里想…） | 删，或换成物件动作 |
| 全知叙述（原来他早就…） | 删，改成后来揭晓 |
| 回忆段 | 改成「回忆」场景，给视觉标记（色调/画幅） |
| 作者议论 | 全删 |
| 时间跨度交代 | 改成字幕或一句台词 |

### 步骤 1.4 —— 转译（改编四步之第二步）

**把情绪转成演员能演的动作**：

| 原文 | 转译 |
|---|---|
| 她心如刀割 | 她用拇指擦屏幕上姑娘的脸，像擦一块污渍。擦不掉 |
| 他很愤怒 | 他把红包按进她手里，握了一下才松开 |
| 她想起了往事 | 手机置顶对话框跳出一个红点 |

### 步骤 1.5 —— 定改编范围

```
必须问用户的两件事：
1. 单集成片时长？（60 秒 / 90 秒 / 120 秒）—— 不问不许往下走
2. 多集时的总集数或改编范围？（全本 / 前 N 章 / 第 X–Y 章）
```

### 步骤 1.6 —— 建时长账本

```markdown
# 时长账本
| 集 | 对应原文章节 | 目标秒数 | 场数 | 字数预算 |
|---|---|---|---|---|
| EP01 | 第 1–2 章 | 90s | 4 | 600 字 |
| EP02 | 第 3 章 | 90s | 5 | 600 字 |
```

🔴 **各镜秒数之和必须等于目标时长**（60 集 × 90 秒的账，一秒都不能差）。

---

## 铁律

1. **先建事实账本，再动刀。**
2. **心理描写一律删或转译**，不许留。
3. **单集时长缺失时必须停下来问**，不许自己猜。
4. **每步输出后对照原文做剧情保真自检**（漏掉的情节要登记）。
5. **各集秒数之和 = 目标总时长。**

---

## 常见坑

| 坑 | 症状 | 解法 |
|---|---|---|
| **忠实到不能拍** | 保留了大量心理描写 | 步骤 1.3 全部剥离 |
| **改到认不出原著** | 情节丢失严重 | 步骤 1.6 的保真自检 |
| **篇幅失控** | 一章塞进一集，超时 3 倍 | 按时长账本反推，一章可能要拆 3 集 |
| **倒叙照搬** | 观众看不懂 | 按故事发生顺序重排，或给回忆视觉标记 |
