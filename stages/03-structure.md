# 阶段 3 · 结构、集纲与钩子

> **一句话**：60 集的剧，是设计出来的，不是写出来的。
> 🔴 本阶段决定这部剧的生死 —— 节奏塌了，第 4 阶段的对白再好也救不回来。

---

## 何时进这一阶段

- 选题卡或改编方案已定，要排 60 集
- 用户要「分集大纲 + 付费卡点」

## 步骤

### 步骤 3.1 —— 定时钟与引擎

```
时钟：倒计时（49 天七七）/ 周期拆封（七封信）/ 阶梯升级 / 双线汇合
引擎：每一轮都是「对手出手 → 主角拆招 → 多出一条线索 → 下一个人急着出手」
```

**引擎必须写成一句话**，后面 60 集全部照这个循环走。

示例（《七格药盒》）：
> 每一轮都是顾家有人出手赶她、栽赃她或者要她的命，姜禾用药剂师的专业眼光
> 和护工对这座房子的熟悉拆招，拆招的过程里总会多出一条指向凶手的线索，
> 而这条线索又会让下一个人急着出手。对手按四种手段依次升级：
> 先管房子（周曼琳），再动钱（顾承安），再走程序（顾承泽），最后是一直在帮她的那个人（顾念）。

### 步骤 3.2 —— 分卷

```
第一卷 · 赶（1–10 集）   立住规则 + 主卡点
第二卷 · 陷（11–30 集）  升级 + 中段反转（真凶换人）
第三卷 · 夺（31–46 集）  战场搬家
第四卷 · 清（47–60 集）  兑现所有伏笔 + 结局承诺
```

🔴 **每卷要有独立的两个字命名**（赶/陷/夺/清），这是节奏的锚。

### 步骤 3.3 —— 排卡点

| 参数 | 值 |
|---|---|
| 第一个卡点 | **第 10 集**（±2） |
| 卡点集占比 | **10–15%** |
| 60 集常用 | 第 10 / 第 29 / 第 46 集 |

**卡点三要素**（见 `references/短剧节奏与付费卡点.md`）：
1. 停在**揭晓的前一秒**
2. 欠的是观众**已押上的赌注**（用已认识的人、已懂的规则）
3. **卡点集自己的局部结果先兑现**（先有实打实的损失，再停）

### 步骤 3.4 —— 逐集排

每集一行，格式：

```markdown
**EP10 手铐** ｜第 8 天 ｜🔒 **付费卡点①**
警方在储藏间床板夹缝里搜出一个地高辛空瓶，瓶身上全是她的指纹。
周曼琳当着全家说："人赃并获。"唐砚掏出手铐，扣上了第一只。
姜禾说："瓶子给我看一眼。只看一眼。"她盯住瓶底那张药房标签，脸色变了。
→ 停在她开口之前。

**出去状态**：唐砚解开了手铐，但她还在名单上，而名单上的人只剩三个。
```

🔴 **每集必须写「出去状态」** —— 这一行决定下一集怎么起。没有它，连续剧会断链。

### 步骤 3.6 —— 结局承诺

```
真凶落网，姜禾洗清五年前的罪名、重新拿回执照；
62 亿她一分没拿去自己花，用来召回药品、赔偿 2021 年的受害者。
感情线留白。
```

🔴 **巨额财物必须有正当去向**（炫富是合规红线）。

## 铁律

1. **没有时钟的故事不许排 60 集。**
2. **卡点必须停在揭晓前一秒**，绝不能揭晓。
3. **卡点前 3–5 集要把欠条一张张发出去。**
4. **每集必写出去状态。**
5. **中段（约第 30 集）必须有反转**，不然必塌腰。
6. **每集 3–5 场、600–800 字**（1–2 分钟装得下）。

---

## 常见坑

| 坑 | 症状 | 解法 |
|---|---|---|
| **中段塌腰** | 20–40 集无事发生 | 加中段反转（真凶换人/两条罪两条路） |
| **卡点含蓄** | 「她拦下一辆网约车」 | 停在揭晓前一秒 + 先兑现局部损失 |
| **钩子靠情绪** | 「她握住了门把手，停住了」 | 换成事件式钩子 |
| **每集太满** | 一集塞 8 场，超时 3 倍 | 按 400 字/分钟折算，超了就砍 |
| **伏笔断线** | 第 3 集埋的东西第 60 集没提 | `series_bible.py qc` 报出来 |
