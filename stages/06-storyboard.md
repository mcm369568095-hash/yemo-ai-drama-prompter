# 阶段 6 · 分镜与镜头设计（核心）

> **一句话**：`shots.json` 是单一真相源。改它，提示词、清单、成本试算全部跟着变。
> 本阶段是本技能的看家本事 —— **导演层派发 + 资产冻结**。

---

## 何时进这一阶段

- 剧本文稿已定（或给了故事/文章/一句主题），要拆成镜头
- 用户说「做分镜」「排镜头」

---

## 输入 / 输出

| | 内容 |
|---|---|
| **输入** | 剧本（或故事 / 文章 / 一句主题） |
| **输出** | `shots.json`（单一真相源）+ 导演层派发表 + 体检报告 |
| **下游** | 阶段 7（提示词） |

## 步骤

### S0 接单三问（缺哪个问哪个）

1. **什么题材？** → 决定用哪套导演预设（`drama` / `suspense` / `warm` / `epic`）
2. **多长？** → 110 秒 ≈ 22–28 镜；30 秒 ≈ 6–8 镜。**先定时长，再反推镜数**
3. **什么画幅？** → `16:9` 横屏 / `9:16` 竖屏。🔴 首帧图必须与出片画幅**严格同比例**

```bash
"$PY" "$SK/init_workdir.py" "$WD" --title "我的短剧" --preset drama
# 脚手架：建目录 + 复制示例 + 顺手冻结资产
```

### S1 拆节拍（Agent 的活，不写代码）

把故事切成一镜一个动作。判据三条：

- **一镜一件事**。一镜里「推门 + 说话 + 转身」= 三镜。
- **一镜 3~6 秒**。写不出动作的节拍，说明它不该是一个镜头。
- **先定情感峰顶，再决定钱花在哪**。曲线低的地方走静态推拉（免费），峰顶才买真视频。

🔴 **宁可多切镜，不要长镜头塞动作**（实测：7 秒特写塞 9 个表情节拍 → 脸几乎不动；
拆成三个 2–3 秒镜头才正常）。

### S2 写 `shots.json`（单一真相源）

```json
{
  "title": "最后一班地铁",
  "preset": "drama",
  "target_sec": 110,
  "ratio": "16:9",
  "style": "电影感写实动画，冷蓝夜色调，霓虹反光，浅景深，颗粒质感",
  "ref": "cast/定稿/主角定稿.png",
  "shots": [
    {
      "id": "c01",
      "beat": "空站台·末班车",
      "cast": [],
      "size_hint": "全景",
      "sub": "末班地铁还有三分钟进站，站台上只剩两个人。",
      "ff": "（首帧画面描述，不要写景别，景别交给导演层）",
      "v": "（只写动作，不要写运镜，运镜交给导演层）"
    }
  ]
}
```

**三个字段最容易写错**：

| 字段 | 规则 |
|---|---|
| `cast` | 本镜同框角色名。**写 `[]` = 本镜没有角色（空镜）**，不硬塞角色设定 |
| `size_hint` | 作者指定的拍摄意图，导演层**优先采纳**（不填则自动派发） |
| `v` | **只写动作**。写运镜会和派发结果打架 |

完整样例见 `templates/shots.example.json`。

### S5 导演层派发

```bash
"$PY" "$SK/story_plan.py" "$WD" --preset drama           # 干跑，看派发表 + 体检报告
"$PY" "$SK/story_plan.py" "$WD" --preset drama --apply   # 写回 shots.json
"$PY" "$SK/story_plan.py" "$WD" --check                  # 只体检，评分<70 直接 exit 2
```

导演层把「什么样的剧情，配什么样的镜头」固化成表：

| 派发什么 | 依据 | 硬约束 |
|---|---|---|
| **景别** | 四套预设的配比 + 剧情张力位置 | 相邻两镜不得同景别 |
| **运镜** | 张力档位 L0~L4（静/缓/中/快/冲击） | 一镜一运镜；L4 全片 ≤3 次且不连用；方向交替 |
| **光位** | 四段情绪序列 | 相邻不得同光位；全片 ≥4 种 |
| **构图** | 按景别分池 | 相邻不得重复；全片 ≥5 种 |
| **时长** | 张力定基调，**字幕字数设下限** | 单镜 3~6s；字幕宁可给余量 |
| **转场** | 段落边界溶解，其余硬切 | 默认硬切，别全片溶解（拖沓） |

**派完自动打分：镜头多样性评分 < 70，不许进入出片环节。**

四套预设见 `references/导演层预设库.md`（drama / suspense / warm / epic）。

---

## 铁律（导演层专属）

1. **景别由导演层说了算。** `ff` 里别自己写景别，会被剥掉。
2. **运镜由导演层说了算。** `v` 里别自己写机位。
3. **作者指定景别优先于自动派发**（有人的镜头不许被派成空镜）。
4. **单镜 3~6 秒**，长镜必崩。
5. **多样性评分 < 70 不许进下一阶段。**
6. **旁白语速按 4.0 字/秒**（童声 3.6，用 `--sub-cps 3.6` 切档）。

## 常见坑

| 坑 | 症状 | 解法 |
|---|---|---|
| **`open` 不是合法 xfade** | 转场链报 `Not yet implemented` 并静默回退全硬切 | 装配时映射成 `fade` |
| **`ff` 自带景别打架** | 模型不知道听谁的 | 派发时剥掉正文里的景别词 |
| **空镜被塞角色设定** | 「画面中没有人物」里塞了角色设定 | `cast: []` 必须返回空 |
| **有人的镜头被派成空镜** | 「一起去看东西」变成空景 | `size_hint` 优先采纳 |
| **首帧画幅不对** | 出片 16:9，首帧 3:2，被裁切 | 严格同比例 |
| **时长没反推镜数** | 16 镜 × 4.5s = 72s 偏短 | `--target-sec` 会告诉你差几镜 |
| **纯环境句写在时间轴里** | 「第 3 秒：柔和晨光」→ 不动的镜头 | 挪出时间轴 |
