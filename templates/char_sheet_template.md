# 多视图角色设定图 · 参数化模板

> 本模板由用户给的一句「角色设定图」提示词提炼而来，作为**人物定稿图生成器**
> （`gen_char_sheet.py`）的内置骨架。固定部分每次都写，可变槽位由用户输入填。
> 生成的图 = 角色圣经（人看 + 一致性校验），真正出图出片只认从它衍生的**干净单图锚定**。

---

## 一、原始提示词（样例，已分析）

```
角色设定图
多视图排版，脸部特写，正面全身，侧面全身，背面全身，画面左下角附带Q版迷你小人插图，
1位知性清冷办公室御姐，韩系3D二次元OC建模，淡粉清透妆容，黑色半扎高马尾长发，
碎刘海，无框细边眼镜，藏青色无袖高领紧身背心，灰色褶皱包臀短裙，白色挂绳工牌，
黑色透肤丝袜，黑色一字带细高跟凉鞋，冷白细腻肌肤，影棚柔和柔光，浅灰色纯色简约背景，
完整全身出镜，面料细节清晰，8k，超精细，OC渲染人物设定稿
```

## 二、拆解：固定骨架 vs 可变槽位

| 区块 | 性质 | 内容 |
|---|---|---|
| ① 排版声明 | **固定** | 多视图排版：四宫格（脸特写 / 正面全身 / 侧面全身 / 背面全身）+ 左下角 Q 版迷你小人 |
| ② 角色数量/定位 | 可变 | `N` 位 + 人设一句话（如「1 位知性清冷办公室御姐」） |
| ③ 美术风格 | 可变 | 如「韩系 3D 二次元 OC 建模，OC 渲染人物设定稿」 |
| ④ 面部与妆容 | 可变 | 如「淡粉清透妆容，碎刘海，无框细边眼镜」 |
| ⑤ 发型 | 可变 | 如「黑色半扎高马尾长发」 |
| ⑥ 服装 | 可变 | 上装 / 下装 / 鞋履 / 配饰，逐项列清 |
| ⑦ 肤质 | 可变 | 如「冷白细腻肌肤」 |
| ⑧ 灯光与背景 | 可变 | 如「影棚柔和柔光，浅灰色纯色简约背景，面料细节清晰」 |
| ⑨ 画质 | **固定** | 完整全身出镜，面料细节清晰，8k，超精细，OC 渲染人物设定稿 |

**铁律**：②~⑧ 是用户给的「角色 DNA」，一旦定稿就**写死进 `cast.json` 的 `features`**，
下游 asset_lock 逐字复用，一个字都不许改。①⑨ 是模板自带，每次必写。

## 三、参数化模板（脚本内置，可直接喂文生图）

```
角色设定图。
多视图排版：画面划分为四宫格 + 左下角 Q 版 ——
  ① 脸部特写（肩部以上，居中）
  ② 正面全身（完整全身出镜，双脚入画）
  ③ 侧面全身（90° 侧身，展示轮廓与服装侧面线条）
  ④ 背面全身（展示后背设计与发型后视图）；
  画面左下角附带 Q 版迷你小人插图（二头身 chibi，同款服装）。
{archetype}。            ← ② 角色数量/定位
{style}。                ← ③ 美术风格
面部与妆容：{face}。      ← ④
发型：{hair}。           ← ⑤
服装：{outfit}。         ← ⑥
肤质：{skin}。           ← ⑦
灯光与背景：{light}。     ← ⑧
完整全身出镜，面料细节清晰，画面中不出现任何文字，8k，超精细，OC 渲染人物设定稿。   ← ⑨
```

## 四、配套「干净单图锚定」提示词（关键！）

🔴 **多视图板绝不能直接喂 `--edit`**——会被整板复刻成多人合影（见技能踩坑清单）。
所以人物定稿图生成器会**额外**产出两张干净单图，作为真正出图出片的锚定：

**全身主锚定 `ref_main`（喂首帧 `--edit` 用）：**
```
single full-body portrait of one {archetype}, {style}。
面部与妆容：{face}；发型：{hair}；服装：{outfit}；肤质：{skin}。
{light}。
single character only, centered, complete full body including feet,
plain clean background, no layout grid, no text, no other people, 8k, ultra detailed。
```

**特写锚定 `ref_face`（近景/特写用）：**
```
close-up face portrait of one {archetype}, {style}。
面部与妆容：{face}；发型：{hair}；肤质：{skin}。
{light}，构图居中，肩部以上，single character, no text, 8k, ultra detailed。
```

## 五、用户输入方式（三选一）

1. **结构化**：`--archetype / --style / --face / --hair / --outfit / --skin / --light` 逐项给。
2. **JSON**：`--spec-json spec.json`，键同上。
3. **整段粘贴**：`--free "把原始提示词整段贴进来"`，脚本会自动抽取已知槽位、剩余塞进对应区块。

生成产物落 `cast/定稿/`：
- `<name>_设定图.png`（角色圣经，人看）
- `<name>_全身.png`（`ref_main`）
- `<name>_特写.png`（`ref_face`）
- 同名 `_prompt.txt` 三份（不设出图命令时留给人工）
