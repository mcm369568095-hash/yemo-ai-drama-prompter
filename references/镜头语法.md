# 镜头语法（lens）—— 让静态首帧也「会呼吸」

> 本表用于**可选出片模块**（`provider.py` 的 KenBurns 通道）：把一张静态首帧
> 推拉成有呼吸感的运动镜头，**成本 0**。过渡镜、铺垫镜全用它，钱只花在情感峰顶。
> 写在 `shots[].lens`，不写默认 `kb_in`。

| key | 动法 | 情绪 | 用在哪 |
|---|---|---|---|
| `kb_in` | 缓慢推近 | 专注、逼近 | **默认**，讲述/聚焦 |
| `kb_out` | 缓慢拉远 | 抽离、回望 | 收尾、感慨 |
| `kb_left` | 向左平移 | 巡视、展开 | 长画卷/场景交代 |
| `kb_right` | 向右平移 | 推进、叙述 | 同上，方向交替防单调 |
| `kb_up` | 向上平移 | 上升、升华 | 情感上扬 |
| `kb_down` | 向下平移 | 沉落、压迫 | 悲剧/沉重节点 |
| `kb_in_l` | 推近 + 左移 | 电影感 | 复合运动，最有「大片味」 |
| `zoom_punch` | 快速冲击推 | 惊变、冲击 | 🔥 高潮句专用 |
| `static` | 完全静止 | 静默、庄重 | 需要看清细节 / 严肃定格 |

## 三条使用铁律

1. **节奏不能平**：连续三镜都用 `kb_in` 会显得呆。
   推荐交替：`kb_in → kb_right → kb_out → zoom_punch → kb_in_l`
2. **高潮必用 `zoom_punch`**：一集里最多 2~3 次，多了就麻木了。
3. **`static` 留给要「看清」的画面**：字卡、关键道具、碑文 —— 静止本身就是强调。

## 转场（跟着剧情走）

| 场合 | 建议 |
|---|---|
| 同一幕内 | `fade`（柔）或 `hard`（干脆） |
| 跨幕 | `zoom` 或 `split`（有段落感） |
| 情绪转折点 | `wipe`（干净利落） |
| 时间流逝/回忆 | `cover`（覆盖感） |

## 时长与呼吸

- 单镜 **3~6 秒**是甜区。短于 3 秒观众来不及看，长于 12 秒必困（`zoom_punch` 除外）。
- 每个镜头尾留 **0.6~1.2 秒**余韵。

## 底层实现备忘（ffmpeg zoompan）

```
scale=3840:2160:force_original_aspect_ratio=increase,crop=3840:2160,
zoompan=z='起点+跨度*(on/总帧)':x='…':y='…':d=总帧:s=1920x1080:fps=25
```
- 🔴 前置 `scale` 到 2 倍再 zoompan，否则推近会糊（采样不足）。
- 🔴 `d` 必须给**总帧数**，写 `d=1` 会抖成灾难片。
- 🔴 `fps` 放在 zoompan 后面设，否则帧率错。
- 🔴 坐标是**相对当帧 zoom 的中心**，公式别自己乱改：

  `x = iw/2 - (iw/zoom/2) + iw*px*(on/总帧)`
