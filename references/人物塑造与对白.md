# 人物塑造与对白

> 夜秣原创归纳 · 提炼自 33 份盲测稿中四份全胜稿的人物写法。
> 一句话：**配角不是工具人，情绪不落在心里，落在物件上。**

---

## 一、人物小传八要素（缺一不可）

赢家的人物小传都包含这 8 项，缺项的稿子在盲评里一律判输：

```markdown
## 姜禾 · 女主 · 28 岁

**表面身份**：（别人眼里她是谁，别人怎么称呼她）
**真实过去**：（被藏起来的那件事，要具体到数字和时间）
**为什么留下**：（动机，钱要排在最后 —— 排在前面的一律判套路）
**能力（她的武器）**：（2–3 条，要具体到"一眼看出瓶签不对"）
**底线**：（她绝不做的事 —— 这一条后面会让她付出代价）
**弱点**：（习惯性的自我毁灭模式，前期必吃亏）
**弧线**：（身份转变的四级台阶 + 最后一个选择）
**标志物**：（2–3 件，后面要变成物证）
**说话方式**：（短句/引条款/不解释/被逼急了只报事实）
```

### 1.1 各项的硬性要求

| 项 | 硬性要求 | 反例 |
|---|---|---|
| **真实过去** | 必须带**具体数字和时间**（"每月 3000 块，打了五年，一次没断"） | "她有一段痛苦的过去" |
| **为什么留下** | **钱要排在最后**。排在前面 = 套路 | "为了钱她忍了下来" |
| **能力** | 必须能**推着剧情走**（药剂师的眼睛 → 一眼看出药片规格不对） | "她很聪明" |
| **底线** | 后面必须让她**真的吃亏**（哪怕推给反派最省事，她也不推） | 写了但从不触发 |
| **弱点** | 前期必须让她**实实在在输一次** | 写了却不影响剧情 |
| **标志物** | 必须变成**物证**（七格药盒 → 全剧第一条物证） | 装饰品 |
| **说话方式** | 每人一套口气，能盲听辨人 | 全员一个腔调 |

## 二、配角：工具人检测

🔴 **工具人 = 只为给主角递信息 / 制造麻烦而存在的角色。**

配角及格的三个标志（盲评赢家全中）：

1. **有自己的动机**：管家护着老太太，是因为她儿子在老太太手里。
2. **有自己的底线**：佣人说「调包可以，杀人不行」—— 她会帮忙，但有止境。
3. **有自己的转变**：被辞退的佣人后面回来指证，是因为主角给过她一句好话。

| ✅ 活的配角 | ❌ 工具人 |
|---|---|
| 「调包可以，杀人不行」 | 「少奶奶，这是太太让我放的」 |
| 「我爸剩下的半瓶，我留了五年，就等着告你」 | 「我要报仇」 |
| 「你凶满满！」（阿尔茨海默的老太太护着主角） | 「她真是个好人」 |

## 三、反派：脸谱化检测

🔴 **脸谱化反派 = 台词全是"三天，你就回来求我"这种宣言。**

反派及格的三个标志：

1. **动机能被理解**：她怕的不是坐牢，是父亲在全家人面前说出她做过的事。
2. **策略是迂回的**：她从不正面动手，只帮忙，在帮忙中拿信息，顺手改证据。
3. **有被逼到绝境的时刻**：后段她牺牲大哥、最后才亲自出手。

**真凶设计（高级）**：
- 表面是全家唯一对主角好的人
- 动机是**怕被揭穿**，不是贪财
- 前 30 集不暴露，但每集留一条**公平线索**

### 公平线索表（必须写）

真凶每次出场的微动作，要提前记在表上，观众回头看时每一条都对得上：

| 集 | 线索 |
|---|---|
| 第 3 集 | 送汤时，视线在药盒周五那格停了一下 |
| 第 6 集 | 主角当众背出批号，窗边的她手指收紧 |
| 第 8 集 | 拆第一封信时，她手里的茶杯磕到了碟沿 |
| 全程 | 一直戴着母亲留下的翡翠镯子（第 56 集监控截图的关键） |

## 四、对白：口吻分离（盲评第一权重）

> 赢家共性第一名：**台词短，人物各有口气。**

### 4.1 三项硬指标

| 指标 | 要求 |
|---|---|
| 长度 | 单句 ≤ 15 字，多数是短单句 |
| 区分度 | 遮住人名，能听出是谁在说话 |
| 信息量 | 一句里只装一个意思，不许带解释 |

### 4.2 口吻分离的做法

给每个角色定一套**语言指纹**：

| 角色 | 语言指纹 |
|---|---|
| 保洁员 | 「缝里也刷。」「哎。」短，不带情绪词 |
| 贵太太 | 「我说，铺块地毯。」重复自己的话，命令不解释 |
| 律师 | 引条款，语速慢，从不提高音量，动了情绪反而说半句就停 |
| 老太太 | 儿歌、认错人、只说过去的话 |
| 中介 | 大嗓门压成小嗓门，句尾带追问「听见没？」 |

### 4.3 对白避坑

| ❌ 病名 | 症状 | 处方 |
|---|---|---|
| **旁白化台词** | 人物说出只有作者知道的事 | 删掉，改成动作 |
| **全员一腔调** | 遮住人名分不出谁在说 | 每人发一套语言指纹 |
| **宣言式台词** | 「三天，你就回来求我」 | 改成具体的动作威胁 |
| **转述式台词** | 「你知不知道她当年做了什么」 | 让说话人当场看见证据 |

## 五、情绪落在物件上（逆袭的那一招）

🔴🔴 **这是赢家和输家的分水岭。**

| ❌ 心理描写（上不了屏） | ✅ 物件动作（能上屏） |
|---|---|
| 她心如刀割 | 她用拇指擦屏幕上姑娘的脸，像擦一块污渍。擦不掉 |
| 他很紧张 | 茶上的热气是直的 —— 她站了有一会儿了 |
| 她想起了女儿 | 手机置顶对话框跳出一个红点 |
| 他强忍着愤怒 | 他把红包按进她手里，握了一下才松开 |
| 她崩溃了 | 张妈在厨房里哭到发抖 |

### 5.1 物件的三条铁律

1. **物件要重复出现**（七格药盒、切药器、手背旧烫疤）—— 重复三次就成了符号。
2. **物件要能被破坏**（碗磕裂、断掉的美甲、攥皱的纸袋）—— 破坏的瞬间就是情绪。
3. **物件要能当证据**（瓶底刻了"禾"字、切药器的固定斜度）—— 情绪和剧情同一件东西。

### 5.2 物证链

把物件串成链，每一环都能被指认：

```
七格药盒 → 周五那格的两片整片（剂量不对）
        → 半片的切口有固定斜度（她的切药器）
        → 第二天清晨变成半片（有人进过屋）
        → 卡在门后的椅子被挪开半尺（证明有人进过屋）
```

## 六、弧线：四级台阶 + 最后一个选择

```
护工（被赶出门）
  → 嫌疑人（被全家围猎）
    → 继承人（在董事会上拿表决权）
      → 站回药房柜台后面（清掉五年前的罪名）
```

**最后一个选择必须是放弃** —— 第 48 天夜里，为了救张妈离开老宅，主动放弃 62 亿。
没有放弃的弧线，观众记不住。
