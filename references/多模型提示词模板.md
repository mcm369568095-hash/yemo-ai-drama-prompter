# 多模型提示词模板

> 本技能的核心资产：同一条镜头，按目标视频模型吐出**该模型的母语**。
> 夜秣原创 · 四套模板全部为本技能自研：通用四段式 / Seedance 七段式 / MiniMax H3 六段式 / 可灵 五段式。

---

## 一、选模板

| 目标模型 | 模板 | 段落数 | 本技能命令 |
|---|---|---|---|
| Seedance 2.5 / 2.0（即梦） | **七段式** | 7 | `--model seedance` |
| MiniMax H3 | **六段式** | 6 | `--model minimax` |
| 可灵 Kling | **六段式（可灵版）** | 6 | `--model kling` |
| 通义万相 Wan | 六段式 | 6 | `--model wan` |
| Veo / Sora | 五段式 | 5 | `--model veo` |
| 通用（默认，本技能原创） | **四段式** | 4 | `--model generic` |

```bash
"$PY" "$SK/shot_prompt.py" "$WD" --apply --model seedance
"$PY" "$SK/model_adapter.py" "$WD" --model minimax --apply       # 已有提示词，只换外壳
"$PY" "$SK/model_adapter.py" "$WD" --list                       # 看所有模板
```

## 二、通用四段式（本技能原创，默认）

```
【画面】<首帧画面 + 角色一致性锁 + 场景 + 时间/天气>
【动作】<时间轴分段：第0-2秒 / 第2-4秒 / 第4-6秒，每段一个物理动作>
【镜头】<景别 + 运镜 + 光位 + 构图>
【约束】<No native dialogue / 无字幕无水印 / 时长>
```

**为什么是四段**：模型只抓前 30 个字。四段把「谁在场」放在最前，
把「不要什么」放在最后（否定词只有字幕/水印/文字/畸形这四类真听得懂）。

## 三、Seedance 2.5 / 2.0 七段式

```
【参考】<@Image1 角色参考图 / @Image2 场景参考图 / @Video1 上一镜尾帧>
【主体】<角色，逐字复用资产冻结块；五官/发型/服装/比例与参考图完全一致>
【背景】<场景 + 时间 + 天气 + 光位>
【时间线】<第0-2秒：…；第2-4秒：…；第4-6秒：…>
【运镜】<一种运镜 + 起止位置>
【风格】<全片 style_lock 逐字复用>
【音频】<环境音 / 无对白 / 音效>
```

🔴 **Seedance 素材上限（官方）**：图片 ≤9、视频 ≤3、音频 ≤3、**合计 ≤12**。
🔴 **10 秒以上必须按时间段分写**，否则后段失控。
🔴 15 秒档建议切 5–6 段、每段 2–3 秒。

## 四、MiniMax H3 六段式

```
【主体】<角色 + 服装 + 状态，逐字复用资产冻结块>
【动作】<物理动作，每个动作句最多 2 个复合动作>
【场景】<地点 + 时间 + 光线>
【运镜】<一种运镜>
【时长】<4–15 秒，每段含 2–4 个镜头>
【音频】<音色 + 对白（<d>对白</d> 标签）/ 无对白>
```

🔴 **H3 的三字段提示词**：主体 / 动作 / 场景，其余为可选。
🔴 **对白用 `<d>...</d>` 标签包裹**，这是 H3 的原生语法。
🔴 Ref2VA 模式：每段 4–15 秒、含 2–4 个镜头。

---

## 五、可灵 Kling 六段式

```
【主体描述】<角色 + 服装，逐字复用>
【动作描述】<物理动作 + 表情，一镜一种>
【场景描述】<环境 + 光线>
【运镜】<一种运镜 + 幅度>
【时长】<5 秒 / 10 秒档位>
【负面提示】<模糊、变形、水印、文字、多余肢体>
```

🔴 可灵对**负面提示词**响应良好 —— 这是少数真听得懂否定的模型，别浪费。

## 六、分段时长铁律（跨模型通用）

> 实测：一个 7 秒特写塞 9 个表情节拍 → PSNR 37–42 dB（**脸几乎不动**）；
> 拆成三个 2–3 秒镜头 → PSNR 降到 22–23 dB。

**结论：宁可多切镜，不要长镜头塞动作。**

| 总时长 | 切段建议 |
|---|---|
| ≤ 8 秒 | 1 段，1 个动作 |
| 8–15 秒 | 2–3 段，每段 1 个动作 |
| 15–30 秒 | 4–6 段，每段 2–3 秒 |
| > 30 秒 | 必须拆成多镜，不许一个长镜扛 |

---

## 七、动作解耦（防肢体融化）

🔴 **每个动作句最多 2 个复合动作。**

| ❌ 会融化 | ✅ 解耦后 |
|---|---|
| 她推开门、走进来、转身、坐下 | 她推开门走进来。｜她转身坐下。 |

**肢体融化高发动作**（要拆或换）：
快速转身 + 挥手、跑动中回头、手指精细操作 + 说话、多人接触。

## 八、跨模型改写对照（常用词映射）

| 通用说法 | Seedance | MiniMax H3 | 可灵 |
|---|---|---|---|
| 镜头缓慢推进 | 缓推，机位前移 | 推镜头 | 推进 |
| 人物面部特写 | 特写，肩部以上 | 近景特写 | 特写 |
| 光线从左侧打来 | 侧光，左主光 | 左侧光 | 侧逆光 |
| 环境与人物都清楚 | 全景，环境可见 | 全景 | 远景 |
| 不要有对话 | 无对白 | 无对白 | 负面：语音、口型 |

## 九、提示词长度

| 模型 | 建议字数 |
|---|---|
| Seedance 2.5（复杂） | 4,300–4,800 字，**上限 5,000**，超限整段压缩 |
| Seedance 2.0 Fast | 15 秒档，约 4,000 字 |
| 通用四段式（本技能） | 300–600 字，**越短越好** —— 超过 800 字模型开始丢信息 |

🔴 本技能立场：**提示词不是写得越长越好。**
四段式控制在 600 字内，让模型每一句都听得见。需要长文时才切七段式。
