# 爆款选题与爽感公式

> 夜秣原创归纳 · 基于 36 份选题、396 场两两盲比的实测数据。
> 一句话：**选题定生死。** 拍得再好，选题废了就是废。

---

## 一、爽感公式

```
爽感 = 消极情绪 × 烈度放大 × 信息差打脸
```

三个因子，缺一个就不爽：

| 因子 | 含义 | 落地写法 |
|---|---|---|
| **消极情绪** | 主角先受辱、先吃亏、先被逼到墙角 | 当众扫地出门、被泼水、被当面撕支票 |
| **烈度放大** | 羞辱要加码，不能只来一次 | 第一次忍了，第二次还忍，第三次忍无可忍 |
| **信息差打脸** | 主角知道对方不知道的事 | 对方撕支票，她翻到第三页看见"护理过失"四个字，把笔推回去 |

🔴 **爽点必须当众落地。** 在镜头外兑现的爽点 = 废。
「她在法庭上赢了」不爽，「她当着全家的面把账本拍在桌上」才爽。

## 二、选题五维评审（写完选题先自查）

| 维度 | 看什么 | 及格线 |
|---|---|---|
| **卖点** | 一句话能不能让人立刻想看 | 一句话内说清"谁 + 被怎么了 + 要干什么" |
| **新意** | 是不是常见套路换个名字 | 至少有一个别人没见过的机制 |
| **冲突和爽点** | 主角要什么、谁挡着、爽点从哪来、能不能一直供得上 | 对手至少 3 档升级 |
| **续航** | 按自己打算的篇幅，中段会不会没戏 | 60 集要有 3 卷以上的事件量 |
| **上屏** | 观众代入谁，爽点落在谁脸上，关键情绪靠不靠心里话撑 | **关键信息必须在画面上** |

## 三、上屏率（最重要、最容易翻车的一条）

**上屏 = 关键信息能不能被演出来。**

| ✅ 能上屏 | ❌ 不能上屏（必须改） |
|---|---|
| 她把账本拍在桌上 | 她在心里算了一遍账 |
| 当票背面写着字，镜头推上去 | 当票上浮现字幕 + 内心独白 |
| 她背出五年前那批药的批号 | 她脑子里闪回前世那本账 |
| 手指在药盒周五那格停了一下 | 她感觉到不对劲 |
| 老太太攥住她手腕喊"满满" | 旁白说"她想起了女儿" |

🔴🔴 **判决规则**：写完后通读一遍，把所有「心里想」「感觉到」「回忆起」「意识到」
改成一个**看得见的动作或物件**。改不掉的，说明这个设计本身不适合拍。

## 四、赢家选题的三个共同做法

### 4.1 少见身份 + 身份翻转

> 「被扫地出门的人，现在拿着整个家的钥匙」（破产管理人）

做法：给主角一个**具体的职业身份**（不是"厉害的人"），
再让这个身份在开场被剥夺、在中途翻转为武器。

| 好身份 | 烂身份 |
|---|---|
| 破产管理人、遗嘱执行律师、药剂师、护工、入殓师、代驾 | 隐藏的绝世高手、传说级律师、战神归来 |

### 4.2 金手指必须配代价规则

> 「只讨真账、多拿反噬」「当面认账才生效」
> 心软说一句「算了」，那笔账就永久消失。

**没有代价的金手指 = 没有冲突。** 规则越具体，故事越能撑长。

| 有好规则 | 没规则 |
|---|---|
| 看见数字但"看见不等于证明" | 能看见一切 |
| 每次使用掉一年寿命 | 无限使用 |
| 只能讨真账，多拿反噬 | 想拿多少拿多少 |

### 4.3 钩子要有画面

> 「首富白天要拆他的铺子，到了夜里却得跪在柜台前求他续当」

一句话卖点里必须有一幅画。**抽象卖点（"她要逆袭了"）没有画面。**

## 五、反套路清单（这些已经被写烂了）

| ❌ 烂大街 | ✅ 替代方向 |
|---|---|
| 重生先知 | 专业身份 + 只有她懂的细节 |
| 鉴宝捡漏 | 职场手艺 + 眼力（药剂师看瓶签、入殓师看手） |
| 全职太太其实是传说级律师 | 真律师被吊销执照，要拿回执照 |
| 战神/龙王归来 | 手艺人回来讨一笔具体的账 |
| 霸总爱上我 | 遗产/债务/契约驱动的利益共同体 |
| 婆媳清算（已被写烂） | 家政/护工视角的雇主悬疑 |
| 冷静期（5 份选题都这么开头） | 换个时间点切入 |

🔴 **最挤的赛道**：离婚 + 查账。36 张故事卡里 18 张提到"账"。
要写就换个**切入角度**（家政阿姨替雇主算账 ≠ 妻子算丈夫的账）。

## 六、🔴🔴 模型默认人名黑名单（必须规避）

实测发现：换哪个技能、换哪个模型，AI 都会掉进同一批名字。
**这些名字一出现，观众就知道是 AI 写的。**

| 类别 | 黑名单 |
|---|---|
| 女主名 | 小满、沈X、名字带「禾」 |
| 男主名 | 顾承泽、国栋、周砚、名字带「砚」 |
| 姓 | 沈、许、顾（过量使用） |
| 配角 | 胖姐、刘姐（已被用滥） |

**规避做法**：
1. 起名前先查本清单。
2. 用**职业 + 年代感**的名字：52 岁保洁员叫「周桂兰」比叫「沈曼」真实。
3. 三代人名字要有年代分层（50 后：桂兰/国栋；70 后：曼/振海；00 后：小满/屿）。
4. 🔴 **最后一个字不要交给模型渲染**（形近字血案：李梦**姝**→李梦**妹**）。
   名字写在版面外，出图后用 PIL 补写。

## 七、选题卡模板

```markdown
# 选题卡 ·《剧名》

**一句话卖点**：（谁 + 被怎么了 + 要干什么，20 字内）

**主角身份**：（具体职业，不是"厉害的人"）
**对手**：（谁挡着，3 档升级怎么排）
**金手指与代价**：（能力 + 破坏它的规则）
**时钟**：（倒计时/周期/阶梯/双线，选一个）
**爽点画面**：（当众落地的那一幅画）
**续航**：（60 集的事件量从哪来）
**上屏自检**：（关键信息在不在画面上）
```

## 八、IP 评估：这个故事值不值得拍

改编小说前，先过这 6 问（A–F 分级）：

| 问题 | 否 = 扣分 |
|---|---|
| 主角有没有一个**具体的、能被演出来的**能力？ | 改编时必崩 |
| 冲突能不能**当众发生**？（不是写信、不是打电话） | 不上屏 |
| 有没有**可被看见的倒计时**？ | 中段必塌 |
| 对手能不能**升 3 档**？ | 撑不过 10 集 |
| 场景数量能不能压到 ≤8 个主场景？ | 成本失控 |
| 关键转折靠不靠**内心独白**？ | 上屏失败 |

**6 个"是" = A 级，4–5 个 = B 级，≤3 个 = C 级（建议换故事）。**
