# 剧本质检规则集

> 夜秣原创的 **Q 系列** 23 条规则，经盲测冠军稿三轮压测校准，误报率归零。

```bash
"$PY" "$SK/script_qc.py" 剧本.md                    # 单集检查
"$PY" "$SK/script_qc.py" 剧本.md --strict            # 严格档（含合规）
"$PY" "$SK/series_bible.py" "$WD" qc                 # 全剧连载检查
```

## 一、单集硬规则（Q1–Q12，违反 = 必须改）

| 编号 | 规则 | 判据 |
|---|---|---|
| **Q1** | **时长装得下** | 正文非空白字数 ÷ 400 ≤ 目标分钟数。超过 = 砍 |
| **Q2** | **每集 3–5 场** | 少于 3 场太薄，多于 5 场必超时 |
| **Q3** | **单镜 ≤ 8 秒** | 长镜必崩（模型撑不住后段） |
| **Q4** | **开头 3 秒有事件** | 开场 3 秒内必须有激励事件或悬念，不许铺垫 |
| **Q5** | **集尾有钩子** | 每集结尾必须停在**揭晓前一秒**，不能是情绪式收尾 |
| **Q6** | **动作句 ≤ 2 个复合动作** | 超过会肢体融化 |
| **Q7** | **对白为主** | OS/VO（旁白、画外）不超过对白的 **1/3** |
| **Q8** | **无上帝视角与心理描写** | 出现「她想」「他感觉」「她意识到」= 命中 |
| **Q9** | **关键信息在画面上** | 关键转折必须有一个可见的动作或物件承载 |
| **Q10** | **台词单句 ≤ 15 字** | 长台词 = 旁白化 |
| **Q11** | **人名词性一致** | 同一人物在场景行/台词行/动作行的称呼要一致 |
| **Q12** | **没有夹带元数据** | 正文里不许出现编号、时长预估、检查点、自检表、模板标签 |

🔴 **Q12 是盲评的头号杀手**：120 场比较里，**110 场的判决理由提到这些要删掉才能用**。
90% 的技能都栽在这条上。交付前必须清稿。

## 二、上屏检查（Q13–Q18）

| 编号 | 规则 | 判据 |
|---|---|---|
| **Q13** | 爽点当众落地 | 爽点不能发生在镜头外、不能靠转述 |
| **Q14** | 情绪有物证 | 每个关键情绪点都有一件物件承载 |
| **Q15** | 反派有动机 | 反派动机可被理解，不是纯坏 |
| **Q16** | 配角有底线 | 配角至少有一句「可以…但不行」式的台词 |
| **Q17** | 主角有具体职业 | 不是"厉害的人"，是药剂师/护工/入殓师/破产管理人 |
| **Q18** | 无空洞形容词 | 命中「声音冷得像冰」「笑意不达眼底」「一字一顿」= 扣分 |

## 三、AI 味检查（Q19–Q23）

| 编号 | 命中词/模式 | 说明 |
|---|---|---|
| **Q19** | 套话形容词 | 冷得像冰 / 不达眼底 / 一字一顿 / 尖声 / 眸色一沉 |
| **Q20** | 三段排比 | 连续三句结构相同的句子 |
| **Q21** | 空洞名词 | 命运、救赎、深渊、执念、宿命（不接具体事件时） |
| **Q22** | 解释性旁白 | 「仿佛」「似乎」「像是」「仿佛在说」 |
| **Q23** | 总结式台词 | 人物说出作者的人生感悟（"人这一辈子啊…"） |

## 四、全剧规则（S1–S8）

| 编号 | 规则 |
|---|---|
| **S1** | 第一个付费卡点在**第 10 集**（±2 集） |
| **S2** | 卡点集占比 **10–15%** |
| **S3** | 分卷 ≥ 3 卷，每卷有独立的主题命名 |
| **S4** | 中段（约第 30 集）有一次**真凶/主线反转** |
| **S5** | 全剧有**一个可见的时钟**（倒计时/周期/阶梯/双线） |
| **S6** | 对手手段至少 **3 档升级** |
| **S7** | 伏笔表里的每条伏笔都有兑现集号 |
| **S8** | 主角弧线有四级台阶 + **最后一个选择是放弃** |

## 五、分镜/提示词规则（C1–C12，本技能精简版）

| 编号 | 规则 |
|---|---|
| **C1** | 资产先行：每镜的角色描述**逐字复用**冻结块，不许改写 |
| **C2** | 一镜一运镜 |
| **C3** | 情绪不写抽象词（写"低头、肩膀轻颤、手指攥住衣角"） |
| **C4** | 「不要」改肯定式（"不要换脸" → "五官与参考图完全一致"） |
| **C5** | 否定词只留给字幕/水印/文字/畸形 |
| **C6** | 单镜 3–6 秒 |
| **C7** | 首帧画幅 = 出片画幅 |
| **C8** | 相邻两镜不得同景别 |
| **C9** | 全片景别 ≥ 4 种、构图 ≥ 5 种、光位 ≥ 4 种 |
| **C10** | L4 冲击运镜全片 ≤ 3 次且不连用 |
| **C11** | 纯环境句挪出时间轴（写在时间轴里会出现空动作段） |
| **C12** | 参考图只给**单人的干净单图**，多视图板/合影一律不喂 |
