# 连载一致性记忆

> 短剧最大的敌人不是单集写不好，是**第 40 集忘了第 3 集埋的伏笔**。
> 夜秣原创设计 · 七份记忆文件体系 + 指纹哈希过期机制。

---

## 一、为什么需要记忆文件

模型没有记忆。你第 40 集问它「三年前她说了什么」，它现编一个。
**记忆文件就是把跨集信息外置成硬盘。**

```
每集创作前：读记忆文件 → 写本集
每集写完后：更新记忆文件 → 落盘
每 5 集：刷新一次故事圣经
```

---

## 二、七份记忆文件

```bash
"$PY" "$SK/series_bible.py" "$WD" init --title "七格药盒" --episodes 60
```

生成 `<workdir>/bible/` 目录：

| 文件 | 内容 | 更新时机 |
|---|---|---|
| `01_故事圣经.md` | 一句话、时钟、引擎、结局承诺、分卷 | 每 5 集刷新 |
| `02_角色档案.md` | 每个角色的表面/真相/能力/底线/弱点/弧线 | 人物有变化时 |
| `03_伏笔表.md` | 每条伏笔：埋下集 → 兑现集 → 状态 | 每集写完 |
| `04_人物关系图.md` | 谁和谁是什么关系，谁欠谁 | 关系变化时 |
| `05_时间线.md` | 剧情天数 → 集号 → 发生了什么 | 每集写完 |
| `06_物品账本.md` | 每个物件出现在哪几集、当前状态 | 物件转手/破坏时 |
| `07_出场登记.md` | 角色在哪些集出场、说了什么关键的话 | 每集写完 |

## 三、伏笔表（防塌腰的核心）

```markdown
| ID | 内容 | 埋下集 | 兑现集 | 状态 |
|---|---|---|---|---|
| F01 | 手背上的旧烫疤（煎药留的） | EP03 | EP28 | ✅ 已兑现 |
| F02 | 切药器的固定斜度切口 | EP03 | EP10 | ✅ 已兑现 |
| F03 | 母亲留下的翡翠镯子 | EP12 | EP56 | ⏳ 待兑现 |
| F04 | 老爷子猜错凶手的那封信 | EP29 | EP57 | ⏳ 待兑现 |
```

🔴 **状态为「⏳ 待兑现」且已过兑现集的 = 断线伏笔**，连载检查会报出来。

```bash
"$PY" "$SK/series_bible.py" "$WD" qc
# → 断线伏笔 N 条 / 人物走形 M 处 / 集号断点 K 处
```

## 四、哈希过期机制

> 上游一改，下游自动标过期 —— 这是 short-drama-production / ai-short-drama 的成熟做法。

```
shots.json 改了  →  提示词全部标 ⚠️ 过期  →  必须重刷
cast.json 改了   →  asset_lock 指纹过期    →  必须 sync
剧本.md 改了     →  分镜表标 ⚠️ 过期      →  必须重导
```

本技能已有的机制：

```bash
"$PY" "$SK/asset_lock.py" "$WD" verify     # 指纹过期数必须为 0
"$PY" "$SK/asset_lock.py" "$WD" sync       # 改了 cast.json 后同步
"$PY" "$SK/series_bible.py" "$WD" status   # 看哪些下游产物过期了
```

## 五、断点续写

长篇连载跑到一半被打断，靠状态文件接着跑：

```bash
"$PY" "$SK/series_bible.py" "$WD" status   # 显示：写到第 N 集，下一步该做什么
```

输出示例：

```
《七格药盒》连载状态
├─ 进度：EP24 / 60（第二卷 · 陷）
├─ 下一步：EP25（第 23 天）
├─ 待兑现伏笔：F03（EP56）、F04（EP57）
├─ 下一个卡点：EP29
└─ 过期产物：prompts/v_c22.txt（shots.json 已改）
```

## 六、跨集一致性检查清单

每写完 5 集，跑一遍：

| 检查项 | 判据 |
|---|---|
| **人设不崩** | 角色的说话方式、底线、弱点在 5 集内保持一致 |
| **物件不丢** | 物品账本里的物件位置和状态连续 |
| **时间不倒流** | 时间线的天数单调递增 |
| **伏笔不断** | 无超期未兑现的伏笔 |
| **称呼不乱** | 同一角色在 5 集内称呼一致 |
| **伤疤不消失** | 受了伤/烫了疤，后面几集还在 |

## 七、与资产冻结的关系

| 维度 | 工具 | 作用范围 |
|---|---|---|
| **视觉一致性**（脸、衣服） | `asset_lock.py` + md5 指纹 | 提示词层面 |
| **叙事一致性**（伏笔、时间、物件） | `series_bible.py` | 剧本层面 |
| **跨集一致性**（人设、称呼） | `series_bible.py qc` | 全剧层面 |

**三者互补，缺一不可。** 只锁视觉不锁叙事，会出现「脸对了但剧情忘了」。
