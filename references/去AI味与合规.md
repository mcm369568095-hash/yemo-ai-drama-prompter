# 去 AI 味与合规

> 夜秣原创归纳 · 结合广电合规条目与 33 份盲测稿评审判据。

---

## 一、AI 味的六种味道

| 味道 | 典型症状 | 处方 |
|---|---|---|
| **套话味** | 「声音冷得像冰」「笑意不达眼底」「一字一顿」「眸色一沉」 | 删掉，改成动作 |
| **排比味** | 连续三句结构相同 | 打乱句式，长短交替 |
| **空词味** | 命运、救赎、深渊、执念、宿命（不接具体事件） | 接上具体的事，否则删 |
| **解释味** | 「仿佛」「似乎」「像是」「仿佛在说」 | 删掉，让画面自己说 |
| **总结味** | 人物说出作者的人生感悟（"人这一辈子啊…"） | 删掉，人物不替作者说话 |
| **完整味** | 每句话都主谓宾齐全、逻辑通顺 | 人会说话不完整，加断句、省略、答非所问 |

---

## 二、去 AI 味的六个动作

1. **把抽象换成物理。**
   「她很悲伤」→「她用拇指擦屏幕上姑娘的脸，像擦一块污渍。擦不掉。」

2. **把长句砍成短句。**
   单句 ≤ 15 字。人说话不复合。

3. **让对话答非所问。**
   「你吃饭了吗」「门锁换了。」—— 人不直接回答。

4. **加打断与重叠。**
   人不会等对方说完。

5. **留半句。**
   「那包药粉……」—— 说半句就停，比说完更有力。

6. **让物件替人说话。**
   不写她紧张，写茶上的热气是直的。

---

## 三、去 AI 味的三条铁律

🔴 **铁律一：宁可不完整，不要完美。**
AI 写的东西句句完整、逻辑通顺 —— 这是最大的破绽。

🔴 **铁律二：具体数字打败形容词。**
「她等了很久」→「她等了五年，每月 15 号转 3000 块，一次没断。」**

🔴 **铁律三：人物不替作者说话。**
人物只说她自己知道的事。总结、感慨、点题 —— 全是作者的嘴。

| # | 红线 |
|---|---|
| 1 | 反对宪法确定的基本原则 |
| 2 | 危害国家统一、主权和领土完整 |
| 3 | 泄露国家秘密、危害国家安全 |
| 4 | 损害国家荣誉和利益 |
| 5 | 宣扬邪教、迷信 |
| 6 | 扰乱社会秩序，破坏社会稳定 |
| 7 | 宣扬淫秽、赌博、暴力 |
| 8 | 侮辱或者诽谤他人，侵害他人合法权益 |
| 9 | 危害社会公德或者民族优秀文化传统 |
| 10 | 蓄意篡改历史、严重违背史实 |
| 11 | 法律、行政法规和国家规定禁止的其他内容 |

### 短剧高发雷区

| 雷区 | 说明 |
|---|---|
| **价值观** | 复仇不能靠私刑，结局必须走法律/程序 |
| **炫富** | 62 亿的遗产，**主角最后要放弃**并用于赔偿 —— 这是标准解法 |
| **迷信** | 重生、先知、算命要有代价规则，不能是无代价金手指 |
| **暴力** | 打脸靠证据和信息差，不靠动手 |
| **医疗** | 涉及药品/剂量要经得起推敲（虚构批号、真实药理） |

## 五、终审清单（三层）

### 第一层 · 内容

- [ ] 无 11 条红线内容
- [ ] 复仇结局走法律程序，不私刑
- [ ] 无炫富结局（巨额财物有正当去向）
- [ ] 虚构的药名/批号不与真实药品冲突
- [ ] 职业描写不污名化具体职业

### 第二层 · 形式

- [ ] AI 生成标识预留位
- [ ] 备案号预留位
- [ ] 片名与宣发名一致
- [ ] 每集编号连续

### 第三层 · 交付

- [ ] 正文已清稿（无元数据、无自检表、无模板标签）
- [ ] 人名词性统一
- [ ] 集尾钩子已逐集核对
- [ ] 付费卡点位置已标注

## 六、交付前必做的「清稿」

🔴🔴 **这是最容易被忽略、也最致命的一步。**

模型写稿时会夹带大量元数据，这些在盲评里是**头号扣分项**：

```
【所属阶段】第 2 幕
【本集结算】爽点 +2
（伏笔，第 44 集兑现）
[连续性] 药盒位置需与第 3 集一致
预估 90.8 秒
EPISODE_ID: EP003
SCRIPT_VERSION: v1.2
认领爽点：□ ○ △
[自检表] 钩子 ✓ 人物 ✓
```

**清稿做法**：正文交付前，用 `script_qc.py` 的 Q12 规则扫一遍，
把所有「【」「（伏笔」「[连续性]」「预估」「EPISODE_ID」「自检表」整段剥掉。

```bash
"$PY" "$SK/script_qc.py" 剧本.md --clean -o 剧本_清稿.md
```
