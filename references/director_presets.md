# 导演预设库（Director Presets）—— 导演层的地基

> 拆镜不由人临场想，由预设派发；人只负责审节奏、改情绪。
> 目的：治「全片一个景别、一个机位、一种光」的同质化。

## 一、为什么必须有导演层

真实的翻车现场：24 个镜头全部中景 + 全片同一种逆光，成片抽帧后
**像同一个人换了 24 次衣服的静态合影**。

根因不是模型不行，是**没有导演层**：没人规定第 5 镜该是特写、第 12 镜该切硬切。

预设 = 把「什么样的剧情，配什么样的镜头」固化成表，脚本按表派发，人只审。

## 二、四套预设（按题材选一套，`story_plan.py --preset <key>`）

| key | 名称 | 适用题材 |
|---|---|---|
| `drama` | 剧情叙事 | 都市情感、家庭故事、成长故事、职场 —— **默认** |
| `suspense` | 悬念反转 | 悬疑、推理、惊悚、反转短片 |
| `warm` | 温情治愈 | 治愈、亲情、日常、宠物、怀旧 |
| `epic` | 史诗宏大 | 古装、神话、战争、大场面、品牌片 |

### 2.1 景别配比（全片强制，`story_plan.py` 会校验）

| key | 大远景/全景 | 中景 | 近景 | 特写 | 空镜/细节 |
|---|---|---|---|---|---|
| drama | 15% | 28% | 34% | 18% | 5% |
| suspense | 18% | 20% | 30% | 25% | 7% |
| warm | 16% | 30% | 34% | 14% | 6% |
| epic | 32% | 28% | 24% | 8% | 8% |

🔴 **硬规则：相邻两镜不得同景别、不得同光位、不得同机位朝向。** 违反即 WARN，必须改。

### 2.2 运镜池与节奏档位

| 档位 | 用在 | drama | suspense | warm | epic |
|---|---|---|---|---|---|
| L0 静 | 开场、收束 | 固定微晃 | 固定 | 固定微晃 | 固定（对称） |
| L1 缓 | 讲述 | 缓推/缓拉 | 缓推/缓拉 | 缓推/缓拉 | 缓推 |
| L2 中 | 发展 | 左移跟/右移跟 | 手持跟 | 横移跟 | 横摇 |
| L3 快 | 冲突/高潮 | 急推/缓升 | 手持急推 | 快速横移 | 仰角缓升 |
| L4 冲击 | 转折点 | 快摇 | zoom_punch/甩镜 | 甩镜 | 快速拉升 |

🔴 **同一个 L3/L4 不得连用**；全片 L4 不超过 3 次（多了麻木）。
🔴 **运镜方向要交替**（左→右→左），避免连续同向平移。

### 2.3 时长带（🔴 核心纪律：单镜 3~6s）

| key | 常规镜 | 情绪镜 | 冲击镜 |
|---|---|---|---|
| drama | 4.0~5.0s | 5.5s | 3.0s |
| suspense | 3.5~4.0s | 5.0s | 2.5s |
| warm | 4.5~5.0s | 6.0s | 3.0s |
| epic | 5.0~5.5s | 6.0s | 3.5s |

**换算**：110s 成片 = **22~28 镜 × 4~5s**。
**镜数换节奏**：镜多了、每镜短了，动作幅度小反而更稳、更耐看。
反例：16 镜 × 10s = 160s，模型撑不住后段，还更贵。

### 2.4 光影序列（四段情绪，写进 `light` 字段）

| key | 序幕 | 发展 | 高点 | 收束 |
|---|---|---|---|---|
| drama | 窗边漫射 | 午后侧光 | 冷调逆光 | 暮色柔光 |
| suspense | 阴云冷调 | 灰蓝低照 | 雨夜冷硬 | 破晓微光 |
| warm | 晨光柔侧 | 午后暖阳 | 金色逆光 | 夕照余晖 |
| epic | 破晓微光 | 正午硬光 | 庄严逆光 | 暖金长影 |

🔴 **同一段内不得连用同一光位**；全片至少 3~4 种光位，否则画面平。
🔴 光线句必须写进首帧 prompt（见 3.2 后缀模板）。

### 2.5 转场规则

| 场合 | 转场 | xfade transition |
|---|---|---|
| 同一幕内镜头相接 | 硬切（默认） | 无（直接 concat） |
| 时间/地点跳转 | 溶解 | `fade` |
| 情绪转折 | 甩 | `slideleft` / `slideright` |
| 段落结束 | 淡黑 | `fadeblack` |
| 回忆/闪回 | 覆盖 | `smoothup` |

🔴 **默认硬切**，只有跳段才溶解 —— 全片 0.35s 溶解 = 拖沓感来源之一。
🔴 第 1 镜的 `open` 只是语义标记，**不是合法的 xfade transition**，装配时必须映射成 `fade`，
否则整条转场链会报错并**静默回退全硬切**（转场全废）。

### 2.6 音效（`sfx` 字段，可选）

可用键：`脚步` `门响` `水声` `风声` `心跳` `铜锣` `鸟鸣` `掌声` `书页` `落石` `雨声` `铃响`
🔴 只在**关键动作节拍**打点，全片 ≤ 6 处。

## 三、字段落点（`shots.json` 每镜）

```json
{
  "id": "c05",
  "beat": "逼问·抽屉里的信",
  "size": "近景",           // 景别（导演层派发）
  "cam": "L2 左移跟",        // 运镜档位
  "light": "冷调逆光",       // 光位
  "compose": "过肩近景",      // 构图
  "dur": 4.5,                // 时长（秒）
  "trans": "hard",           // 转场
  "sfx": "门响",             // 可选
  "ff": "…（首帧 prompt，末尾自动拼镜头语言后缀）",
  "v": "…（只写动作与运镜）",
  "sub": "…（字幕长句）"
}
```

### 3.2 首帧 prompt 的镜头语言后缀（`story_plan.py` 自动追加）

```
【镜头】{size}｜{compose}｜{cam}｜{light}｜主体占画面{占比}%（以本节为准，覆盖前文任何构图描述）
```

## 四、审片关口（人只看两处）

1. **抽帧体检**：`story_plan.py` 自动打分，**评分 < 70 不许进入出片环节**。
2. **逐镜台账**：哪些镜要重跑、跑了几轮，一眼看清，只重跑该重跑的。

> 结论：**AI 负责拆镜与执行，节奏和情绪的决定权必须留在人手上。**
