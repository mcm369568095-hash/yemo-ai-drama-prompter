# 夜秣AI短剧生成器

> 一句话主题进去，60 集短剧 + 全套分镜提示词出来。

**夜秣AI短剧生成器**是一条跑在 [WorkBuddy](https://www.workbuddy.cn) 里的 AI 短剧生产线。
输入一句主题、一段故事、一个剧本，甚至一篇公众号文章，产出一整套**可直接投喂 AI 视频模型**的分镜提示词包。

v2.0 把这条线从「只会下半场」扩成了**九阶段全流程**：上游能选题、改小说、立人物；中游能排 60 集大纲、卡付费点、写剧本、审稿去 AI 味；下游能派分镜、吐多模型提示词、出评审看板。

---

## 🌟 它治什么病

做 AI 短剧的人，都栽在这几件事上：

| 塌方点 | 本技能怎么接住 |
|---|---|
| 😵 人物每帧换脸换装，观众出戏 | **资产冻结**：角色特征写死 + md5 指纹校验，跨镜一致 |
| 🎥 全片一个景别平推到底，像 PPT | **导演层**：自动派发景别 / 运镜 / 光位 / 构图 / 时长 / 转场，并逐镜打分 |
| 📝 提示词不会写，只能抄模板 | **多模型提示词**：同一条镜头，吐出目标模型的母语 |
| 🧑‍🎨 角色定稿图难画，下游还对不上 | **人物定稿图生成器**：文字 → 多视图角色圣经 + 干净单图锚定 |
| 📉 第 40 集忘了第 3 集埋的伏笔 | **连载记忆**：七份记忆文件 + 伏笔埋兑表，写长篇不塌腰 |
| 🤖 剧本一股 AI 味，读着就不像人话 | **剧本质检**：Q 系列 23 条规则 + 一键清稿 |
| 🌀 60 集写到中段就不知道该卡哪 | **付费卡点表**：卡在揭晓前一秒，卡点集自身损失先兑现 |

> 一句话：**不是帮你"写一条提示词"，而是替你把整部短剧"分镜化"。**

## 🔄 九阶段流水线

| # | 阶段 | 干什么 |
|---|---|---|
| 00 | 选题 | 爽感公式验选题、IP 改编价值评估、反默认人名黑名单 |
| 01 | 改编 | 小说 / 网文 → 短剧结构，保留钩子、砍掉水文 |
| 02 | 人物资产 | 人物小传八要素、角色定稿图、资产冻结与特征指纹 |
| 03 | 集纲卡点 | 60 集分集大纲、付费卡点表、每集钩子与「出去状态」 |
| 04 | 剧本对白 | 上屏率铁律（心理描写 → 可见动作）、台词口吻分离 |
| 05 | 审稿去 AI 味 | Q 系列 23 条质检、元数据剥离、合规检查 |
| 06 | 分镜派发 | 导演层自动派发景别 / 运镜 / 光位 / 构图 / 时长 / 转场 |
| 07 | 多模型提示词 | Seedance / MiniMax H3 / 可灵 / Wan / Veo / 通用四段式 |
| 08 | 出片 | HTML 评审看板、成本估算、交付清单 |

## 🧠 文件多，但绝不一次全读

v2.0 文件翻了一倍，但**调度是有序的**：

```
SKILL.md       总控：只做目录 + 六问 + 路由
stages/        9 个阶段模块，按你当前阶段加载
references/    10 份知识库，用时再读
scripts/       14 个引擎
templates/     7 个模板
```

调度中枢是 `drama_router.py`。说一句「60 集分集大纲 付费卡点」，它直接告诉你该读 `stages/03-structure.md` 加哪两份 reference，并给出可执行的命令 —— **不翻全库，只翻当前那两页**。

---

## ⚙️ 五个引擎

| 脚本 | 干什么 |
|---|---|
| `drama_router.py` | 阶段路由：按需求或项目进度，告诉你读哪些文件、跑哪条命令 |
| `model_adapter.py` | **多模型适配**：Seedance 七段式 / MiniMax H3 六段式 / 可灵 五段式 / 通用四段式。双人同框自动挂 2 张参考图，空镜自动留空 |
| `series_bible.py` | 连载记忆：七份记忆文件 + 伏笔埋兑表 + 断线检查 + 断点续写 |
| `script_qc.py` | 剧本质检 Q1–Q23，支持 `--clean` 一键清稿（剥掉元数据、模板标签、时长预估） |
| `review_board.py` | 单文件离线 HTML 评审看板：全片一格一眼过 |

## 📖 怎么用

对 WorkBuddy 说一句就行：

- 「把这篇故事变成 AI 短剧分镜」
